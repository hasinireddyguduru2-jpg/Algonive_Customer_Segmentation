# Customer Segmentation Using Machine Learning

This project was developed as part of Algonive Data Analytics Internship.

## Objective
To segment customers based on income and spending patterns using K-Means clustering.

## Tools Used
Python, Pandas, Seaborn, Matplotlib, Scikit-learn

## Steps Performed
- Data Cleaning
- Exploratory Data Analysis
- Elbow Method
- K-Means Clustering
- Business Insights

## Outcome
Customers were grouped into 5 categories to help businesses improve marketing strategies.
